Rock Paper Scissors
A simple Rock Paper Scissors game built with HTML, CSS, and JavaScript.

The player chooses Rock, Paper, or Scissors, and the computer makes a random choice. The game then shows the result.

Features
- Rock, Paper, and Scissors choices
- Computer makes a random choice
- Displays the game result
- Simple and clean interface
- Interactive gameplay

Technologies
- HTML
- CSS
- JavaScript

How to Play
1. Open the game in a web browser.
2. Choose Rock, Paper, or Scissors.
3. The computer will make its choice.
4. Check the result and play again.

📚 Purpose

This project was created to practice JavaScript basics, user interaction, DOM manipulation, functions, and game logic.
